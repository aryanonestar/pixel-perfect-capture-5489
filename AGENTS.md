## 3. ALGORITHMIC SPECIFICATIONS

### A. PDF Text Extraction, Clustering & Sorting (`renderPage`)
Raw PDF Items (PDF.js) -> Noise Filter -> Two-Column Split -> Y-Proximity Row Grouping -> Visual Sort -> wordMap[]
1. **Extraction:**
   - Execute `page.getTextContent({ combineTextItems: true })` to retrieve raw text items `tc.items`.

2. **Noise & Artifact Suppression:**
   Prior to row grouping, drop any text item matching any of the following criteria:
   - **Header/Footer Boundary:** Items where Y > PageHeight * 0.94 or Y < PageHeight * 0.06 (unless body text explicitly spans into this range).
   - **Footnotes:** Items where fontSize < 0.65 * medianFontSize.
   - **Metadata & Artifacts:**
     - Lone numeric strings (Page numbers: `/^\d+$/`).
     - Web URLs (`/https?:\/\//i`, `/www\./i`, `/doi:/i`).
     - Email addresses (`/[\w.-]+@[\w.-]+\.\w+/`).
     - Citation markers (`/^\[\d+\]$/`).
     - Captions (`/^(Figure|Fig\.|Table)\s+\d+/i`).
     - Encoding artifacts (`/cid:\d+/i` or non-printable unicode glyphs).

3. **Layout & Multi-Column Processing:**
   - **Midpoint Check:** Calculate the page X-midpoint (X_mid = PageWidth / 2).
   - **Column Test:** If > 70% of text items fall distinctly into X < X_mid - delta or X > X_mid + delta, set `isTwoColumn = true`.
   - **Sorting Strategy:**
     - **Single Column:** Group items into visual rows where |Yi - Yj| <= 0.6 * fontSize. Sort rows by Y descending (top to bottom). Sort items within each row by X ascending (left to right).
     - **Two Column:** Partition items into `leftColumnItems` (X < X_mid) and `rightColumnItems` (X >= X_mid). Execute visual row grouping and sorting independently on `leftColumnItems` first, then append sorted `rightColumnItems`.

4. **Coordinate Mapping (`wordMap[]` Construction):**
   - For each sorted text item, split text string by whitespace into individual words.
   - Calculate canvas pixel coordinates (cx, cy, cw, ch) taking into account viewport scale, high-DPI canvas ratio, and baseline offsets.
   - Append `{ word: sanitizedWord, cx, cy, cw, ch }` into `wordMap[]`.

### B. Highlight Tracking Engine (`highlightWord`)

```javascript
function highlightWord(spokenWord) {
  // 1. Sanitize input word
  const cleanSpoken = spokenWord.toLowerCase().replace(/[^a-z0-9]/g, '');
  if (!cleanSpoken) return;

  const LOOKAHEAD_WINDOW = 80;
  const maxSearchIndex = Math.min(wordSearchStart + LOOKAHEAD_WINDOW, wordMap.length);
  let matchIdx = -1;

  // 2. Strict Forward-Only Search
  for (let i = wordSearchStart; i < maxSearchIndex; i++) {
    const targetWord = wordMap[i].word.toLowerCase().replace(/[^a-z0-9]/g, '');
    
    // Exact match required for short words (<= 3 chars) to avoid false positives on 'a', 'in', 'the'
    if (cleanSpoken.length <= 3) {
      if (targetWord === cleanSpoken) { matchIdx = i; break; }
    } else {
      if (targetWord === cleanSpoken || targetWord.startsWith(cleanSpoken) || cleanSpoken.startsWith(targetWord)) {
        matchIdx = i;
        break;
      }
    }
  }

  // 3. Render Highlight if match found
  if (matchIdx !== -1) {
    wordSearchStart = matchIdx; // Advance pointer forward; NEVER move backward
    drawHighlightRectangle(wordMap[matchIdx]);
  }
}
```

### C. Sentence Anchoring (`anchorWordSearch`)
When advancing to a new sentence (`lineIdx++`), lock the initial position in `wordMap[]` using a 2-word tuple:
1. Extract the first two valid words from `textLines[lineIdx]`: W1, W2.
2. Search forward from `wordSearchStart` for an index i where `wordMap[i] === W1` AND `wordMap[i+1] === W2`.
3. If matched, update `wordSearchStart = i`.
4. If no 2-word tuple match is found, fallback to searching for W1 alone within a 40-word forward window.
5. Rule: Never wrap search around to index 0.

### Global Audio Lifecycle Manager:

- `pauseReading()` must immediately call `window.speechSynthesis.pause()` AND `currentAudio.pause()`.

- Summaries must process extracted `pageText` through the built-in AI provider.
- Format output into 4–5 bullet points.
- Fallback gracefully to displaying top 3 key sentences if API connectivity fails.

## 5. EDGE-CASE & STABILITY GUARDRAILS

| Failure Mode | Root Cause | Mandatory Fix / Guardrail |
|---|---|---|
| Blank Page / Frozen Reader | High-DPI canvas overflow or missing font maps | Limit canvas draw scale to <= 2.0x device pixel ratio; wrap `font.loading` promises in `Promise.race()` with a 1.5s timeout. |
| Jumping Highlight | Unsorted PDF object stream | Enforce visual Y-proximity sorting and strict forward-only search (`wordSearchStart`). |
| Zombie Dual Audio | Multiple audio instances playing concurrently | Enforce single-point `currentAudio` cancellation in `stopReading()` and before initiating `readNext()`. |
| XSS Injection via PDF | Malicious script strings inside PDF text metadata | Sanitize all extracted page text before setting `innerHTML` inside summary or log windows. |
